# Векторный поиск с использованием WordNet

## Описание проекта

Этот проект реализует векторный поиск документов в базе данных SQLite с использованием WordNet. Программа позволяет:

- Вводить текст для поиска.
- Находить документы, содержащие семантически близкие фрагменты текста.
- Выводить результаты поиска в графическом интерфейсе.
- Показывать руководство пользователя и отчет о проделанной работе.

## Как работает проект

1. **База данных**: Используется SQLite для хранения документов.
2. **WordNet**: Для вычисления семантической близости слов используется библиотека NLTK и WordNet.
3. **Графический интерфейс**: Реализован с использованием Tkinter.
4. **Поиск**: Программа ищет документы, содержащие слова, семантически близкие к запросу.

## Используемые технологии

- Python 3
- Tkinter (графический интерфейс)
- SQLite (база данных)
- NLTK и WordNet (обработка естественного языка)
